# Code of Conduct

## Our commitment

We want participation in BASTION-KERN GIS to be respectful, constructive, and focused on improving geospatial software for a broad community. Contributors and maintainers are expected to help create a welcoming environment regardless of experience, identity, background, or professional affiliation.

## Expected behavior

- Be respectful, patient, and constructive in technical discussion.
- Critique ideas and code rather than attacking people.
- Assume good intent while addressing harmful impact clearly.
- Respect privacy: do not publish personal information, precise user locations, credentials, or private vulnerability details.
- Respect project scope, third-party rights, data-provider terms, and attribution requirements.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized misconduct, deliberate disruption, or publishing another person's private information are not acceptable. Do not use project channels to promote unlawful surveillance, unauthorized access, or misuse of location data.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. Report conduct that makes participation unsafe by contacting the repository maintainers through a private channel available from the repository owner/profile. Do not report security vulnerabilities in public issues; follow [`SECURITY.md`](SECURITY.md).

Maintainers will review reports fairly and may remove content, issue warnings, restrict participation, or take other proportionate action. They should respect confidentiality and share only information needed to address the report. If a maintainer is involved in a report, contact another repository owner or GitHub Support where available.

This code of conduct applies to project issues, pull requests, discussions, reviews, and other spaces operated for the project.
