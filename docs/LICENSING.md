# Licensing and third-party rights

## Current licensing status

This repository does not currently grant a project-wide open-source license. Do not add a license badge or imply that the application is open source until the rights holder has selected and approved a license. The absence of a license does not grant permission to copy, modify, distribute, or commercially use project materials beyond rights provided by applicable law.

The repository also references or includes Git submodules from independent upstream projects. Each upstream project retains its own license and terms. A project-level license cannot override those terms, and the maintainer must audit each pinned dependency and its license before public distribution.

## Before adding a LICENSE file

1. Confirm who owns or is authorized to license each first-party contribution, including contributions from contractors and collaborators.
2. Inventory submodules, copied assets, fonts, map styles, datasets, and other third-party materials; record their licenses and required notices.
3. Choose a license appropriate to the desired use and obtain approval from the rights holder. For example, permissive code licenses and copyleft licenses have materially different obligations; no license is selected here.
4. Add the exact, unmodified license text and required notices, and update the README with the scope and exclusions.
5. Keep brand names, logos, official emblems, map styles, provider content, and datasets outside the grant unless their owners have expressly authorized that use.

This file is project guidance, not legal advice or a substitute for a rights and license review.
