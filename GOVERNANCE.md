# Governance

## Current project stage

BASTION-KERN GIS is an early-stage starter maintained in the `OFFENTLOGSPOT/bastion-kern-geospatial-intelligence` repository. A formal foundation, steering committee, service-level commitment, sponsorship arrangement, and project-wide software license have not been established by the repository materials reviewed. Do not infer any of these from the project name or roadmap.

## Roles and decisions

- **Maintainers** are the repository owners and collaborators authorized to merge changes. They are responsible for reviewing project direction, release readiness, security reports, and repository settings.
- **Contributors** may propose changes through issues and pull requests. A contribution does not guarantee acceptance or a maintainer role.
- **Users and organizations** are welcome to provide use cases, technical feedback, and proposed collaborations through public issues. Do not post secrets, private data, or exploitable vulnerability details publicly.

Maintainers make decisions based on user impact, correctness, maintainability, privacy, security, data provenance, legal/redistribution rights, and the project's stated scope. For substantial proposals, discuss the problem in an issue before investing in a large implementation. Maintainers should explain material decisions in the issue or pull request so the reasoning is reviewable.

## Changes and releases

Changes should be proposed by pull request, reviewed by someone other than the author when practical, and pass applicable automated checks before merging. Changes to licensing, branding, data providers, privacy claims, production deployment, or repository visibility require explicit maintainer review. Releases should only be tagged after validation and should identify known limitations; the project is not a safety-critical navigation service.

## Conflicts and conduct

All project spaces should follow [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md). Maintainers should disclose relevant conflicts of interest, avoid implying endorsement by providers or public bodies, and record decisions affecting third-party rights or user privacy.

## Governance changes

Propose governance changes through a pull request with rationale and discussion. Maintainers may revise this model as the project develops and its contributor community grows.
